# API & AI Tools

A collection of small applications and experiments built around AI APIs, exploring practical ways to integrate language models, audio processing, image generation, and other AI-powered capabilities into software.

Each project focuses on a specific use case, from conversational interfaces and developer utilities to creative tools and media processing.

## Projects

| Project | Description |
| --- | --- |

| [openai-basic-code-reviewer](./openai-basic-code-reviewer/) | Uses an AI model to review code and provide feedback. |

## Getting Started

Clone the repository:

```bash
git clone https://github.com/QuantumZenoSix/api-ai-tools.git
cd api-ai-tools
```

Choose a project directory and follow its instructions. Dependencies, configuration, and usage vary by project.

### API Keys

Most projects that interact with external AI services require an API key or other provider credentials.

1. Review the selected project's documentation and configuration.
2. Obtain credentials from the relevant provider.
3. Configure credentials using the method supported by that project.
4. Run the application according to its instructions.

**Obviously - try to keep API keys out of source control.** Use environment variables or an appropriately configured local `.env` file where supported, and ensure secrets are excluded from Git.

## What I'm Exploring

- **API integration:** Connecting applications to external AI services.
- **Conversational AI:** Building chatbot interfaces and experimenting with model responses.
- **Developer tooling:** Applying AI to code review and code transformation.
- **Media processing:** Working with audio transcription and image generation.
- **Creative applications:** Exploring AI-assisted color selection and playlist generation.
- **Language-model fundamentals:** Understanding tokenization and the practical details of working with model APIs.
